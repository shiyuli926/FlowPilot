# FlowPilot

把「我要做什么」变成「我什么时候做」。Vue 3 + TypeScript + Pinia + FullCalendar，FastAPI + SQLAlchemy + SQLite，启发式排程与可选 OR-Tools CP-SAT。

当前交付为**本地单用户版**。任务、日程、配置和排程版本均由后端持久化。工作区初始为空，可在首页主动加载示例；已加载的示例可以像普通任务一样编辑。

## 快速运行

需要 Python 3.11+、Node.js 20.19+（或22.12+）。从项目根目录执行：

```sh
python3 -m venv backend/.venv
backend/.venv/bin/pip install -r backend/requirements-optimizer.txt
npm --prefix frontend ci
npm --prefix frontend run build
backend/.venv/bin/uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
```

打开 http://127.0.0.1:8000 。API 文档：http://127.0.0.1:8000/docs 。已有依赖和构建产物时，只需最后一条命令，或 `./scripts/start.sh`。

不需要 CP-SAT 时安装 `backend/requirements.txt` 即可，选择 CP-SAT 时会明确提示回退。

开发前端时，在另一个终端运行 `npm --prefix frontend run dev`，打开 Vite 输出的地址；`/api` 自动代理到8000端口。生产构建更新后刷新浏览器；后端代码更新后需重启后端。

## 使用方法

1. 在设置中配置时区、每周可用时段和规划窗口（默认14天）。
2. 在任务箱建立项目、任务，添加固定课程和会议。支持耗时、剩余工时、优先级、精确或仅日期的截止要求、最早开始、拆分限制、时段偏好及前置依赖。
3. 也可以输入「本周五晚上8点前交电磁场作业，大概3小时；周日之前读完论文，需要4小时」，确认提取字段后批量保存。仅日期的截止要求保留为待确认，不会自动变成23:59。
4. 点击自动规划，查看新增、移除、保留数量和逐块时间，再确认应用。
5. 在日历中点击时间块锁定；拖动或拉伸会在校验通过后锁定，冲突则回滚。固定事件不可拖动。点击固定日程可修改；重复日程支持只修改/取消这一次，也可修改或删除整组。
6. 新增会议、任务或更新进度后会提示重新规划，确认前不会偷偷修改已发布计划。未受影响的时间块优先保留。已完成任务立即释放未来排程。
7. 撤销恢复上一版本，但会重新检查当前数据、固定事件和锁定约束；不安全的恢复会被拒绝。
8. 任务箱每行右侧的垃圾桶、任务详情底部均可删除任务，需确认后执行；删除会立即释放对应日历安排。若其他任务依赖它，需先解除依赖。项目页每张卡片右上角可删除项目，确认后其任务移到「未分类」，已有日程保持不变。任务和项目删除不可通过排程撤销恢复。

例子仅使用本地规则也能运行。离线规则擅长明确的中文相对日期、阿拉伯数字时间、中文/数字耗时、分号或换行分隔的多任务；复杂语义建议接入模型。可以在任务详情中手动纠正提取结果。

## 接入模型（可选）

复制 `.env.example` 为 `.env`，填写后使用：

```sh
backend/.venv/bin/uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000 --env-file .env
```

`LLM_BASE_URL` 为带 `/v1` 的 OpenAI 兼容地址，`LLM_MODEL` 为模型名，`LLM_API_KEY` 为密钥。Ollama 可用 `http://127.0.0.1:11434/v1`，模型需自行下载。密钥只在后端读取。模型接口需支持 `response_format: json_schema` 结构化输出。设置模型接口后，提交解析的文本会发送给所配置服务；未配置时完全使用本地规则。连接或结构校验失败会回退并明确提示。本地 `qwen3:8b` 已完成真实调用验证，云端服务尚未验证。

本机 Ollama 推荐使用 `qwen3:8b`：先执行 `ollama pull qwen3:8b`，然后在 `.env` 中配置：

```dotenv
LLM_BASE_URL=http://127.0.0.1:11434/v1
LLM_MODEL=qwen3:8b
LLM_API_KEY=ollama
LLM_REASONING_EFFORT=none
LLM_TIMEOUT_SECONDS=90
NO_PROXY=localhost,127.0.0.1,::1
```

`LLM_REASONING_EFFORT=none` 通过 Ollama 兼容接口关闭 Qwen3 思考模式，适用于任务字段提取；其他服务未必支持此参数，不需要时省略。`LLM_TIMEOUT_SECONDS` 默认25秒，本地模型首次加载建议90秒。`NO_PROXY` 避免本机请求进入系统代理。配置后重启后端，`./scripts/start.sh` 会自动读取 `.env`。模型失败仍会回退本地规则；解析响应中的 `provider: llm` 表示模型提取成功。解析只返回预览，保存任务仍需确认。

AI 对话支持任务提取、单次及重复固定日程新增和当前计划风险分析。例如输入「明天下午三点到四点开会」，会打开可编辑的日程确认框；也可输入「明天下午三点开会，持续45分钟」。缺少开始或结束时间时需在确认框补全，不会默认一小时。可用分号或换行同时输入任务和日程，勾选需要的项目后整批确认保存；取消不写入数据。

固定日程会立即显示在日历，自动规划会避开它们；已有任务安排需点击自动规划预览更新。与已有固定日程、锁定或正在执行的时间块冲突时拒绝整批保存，避免部分写入。支持每天、工作日（周一至周五）、每周指定一个或多个星期的重复日程，间隔1至12天/周，可设包含当天的截止日期或持续重复。按月、按年重复尚未实现。可用时段修改在设置中进行；聊天不会直接删除或移动日程。任务拆解、任意对话式调整属于后续功能。

## 重复日程

对话示例：「每周三下午三点到四点开组会，直到2026年12月31日」「每天晚上九点到九点半复盘」「每个工作日上午九点到九点半开晨会」。确认框可编辑重复频率、间隔、星期和截止日期；手工新增日程也支持相同设置。

重复规则保存为一个日程组，按用户正在查看的日期范围以及排程窗口展开，不会一次写入大量独立事件。翻到未来月份后仍会出现，自动规划的两种引擎都会避开每一次发生的时段。工作日表示周一至周五，不自动排除法定节假日。

点击日历中的某一次日程，可只修改或取消这一次；也可修改整组。整组改名、改时间或延长截止日期时保留单次例外，更换起始日期、重复频率、间隔、星期或规则时区时清除例外。整组删除需确认。已有日程的 JSON 数据兼容新增可选字段，无需删除数据库或迁移表。

重复时间按规则自身 IANA 时区的当地钟点保持；夏令时春季不存在的那次时间会跳过，秋季重复小时采用第一个有效偏移。创建或修改时检查未来一年，以及显式单次日程、例外和已锁定时间块所在窗口的冲突；无限规则不作永久无冲突保证，每次排程仍会展开当前窗口重新校验。

## 排程保证与边界

- 15分钟粒度，未来规划窗口内安排；固定事件、可用时段、硬截止、最早开始、依赖及锁定为硬约束。预计与剩余时长须为15分钟的倍数。
- 可拆分任务满足单块下限/上限；不足最短块的整个小任务允许一次完成。不可拆分任务必须找到完整连续时段。
- 启发式按截止、优先级排队，优先保留未受影响的已发布安排，偏好时段作为软目标。不是严格的48小时局部求解，而是规划窗口内保留旧安排、补排冲突任务。
- CP-SAT 使用可选区间、NoOverlap 和任务前后约束，限时3秒，目标优先减少未安排工作量，再考虑时间与变动。未安装、超时或校验失败回退启发式。当前 CP-SAT 尚未优化时段偏好，也未实现严格的分层词典序优化。
- 风险中的缺口是**当前排程方案**的结果，不是全局最小缺口或延期概率。只有日期的 DDL 不作为精确硬截止。硬截止不足时保留未完成工作量，不占用睡眠时间或生成重叠任务。
- 正在执行的块保持不动，过去的未完成任务会根据仍记录的剩余工作量重新排入未来；完成量以用户更新为准，没有自动把过去时间记为完成。
- 依赖循环、依赖缺失、锁定冲突均拒绝，预览根据数据修订号防止过期覆盖。提交后保留历史版本。
- 日期显示遵循用户 IANA 时区；日历通过本地墙上时间投影显示，后端计算以真实带时区时间处理。夏令时不存在的时间会被拒绝；秋季重复小时在手工输入时采用转换器找到的一个有效偏移，尚无偏移选择控件。

## 数据与维护

SQLite 默认位于 `backend/flowpilot.db`，可用 `DATABASE_URL` 更改。停止后端后复制数据库文件即可备份。不要删除数据库作为普通重启步骤。SQLite创建独立任务、项目、固定事件、排程版本和应用配置表；完整排程块快照按版本保存。当前没有 Alembic 升级迁移，既有结构变更前应备份并编写迁移。

本版无需 Redis/PostgreSQL；无账号隔离、OAuth、外部日历同步、邮件/PDF导入、通知、PWA离线缓存和个性化预测。仅绑定本机地址运行，不应直接作为公网多用户服务。上线前需要身份验证、数据隔离、迁移与部署配置。

```sh
npm --prefix frontend test

```

后端测试覆盖20任务+一周固定事件+临时会议验收、无重叠、硬截止缺口、依赖/循环、不可拆分、锁定稳定性、完成释放、预览/提交/撤销、批量事务、日期精度及夏令时。前端测试覆盖时区转换与不存在的时间；浏览器人工验证见 `docs/verification.md`。

## 目录

- `frontend/src/App.vue`：日历、任务箱、项目、统计、设置、确认弹窗和助手。
- `frontend/src/stores/`、`services/`、`types/`：状态、API与时区工具、类型。
- `backend/app/main.py`：REST API、事务与排程版本管理。
- `backend/app/scheduler/`：启发式、可选 CP-SAT、约束及风险。
- `backend/app/ai/`：本地规则与兼容模型提取，独立于排程引擎。
- `backend/tests/`：排程和接口测试，使用隔离临时数据库。

技术文档：[FullCalendar v6](https://legacy.fullcalendar.io/v6)、[FastAPI](https://fastapi.tiangolo.com/)、[OR-Tools CP-SAT](https://developers.google.com/optimization/cp/cp_solver)。
