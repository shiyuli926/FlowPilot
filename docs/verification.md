## 重复固定日程（2026-11-04）

- 支持 daily/weekly、1至12天/周间隔、多个星期、包含当天的截止日期或无限重复；工作日为周一至周五。确认框与手工日程表单均可编辑规则。
- 日程组和例外保存于原有事件 JSON；旧单次记录使用默认空规则兼容，无表结构迁移。实例在日历查询范围及每次排程窗口动态展开，实例 ID 由组ID和原始日期确定。
- 两种排程引擎及提交、拖动、撤销校验使用展开后的日程；创建/修改校验未来一年、显式日程和锁定块窗口，未承诺无限规则永久无冲突。
